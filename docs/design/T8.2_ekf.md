# T8.2 EKF design note

## State and inputs
State x = [s, v, b]: arc length along the centerline (m), speed (m/s), residual longitudinal acceleration offset (m/s^2). b carries every constant offset in a_long: accelerometer bias left after alignment and tilt leakage. Input per IMU sample: AlignedSample from the T8.1 Aligner (a_long, sigma_a_long, yaw_rate, valid, mode, sigma_tilt, mount_changed). The EKF passes its own s and v to the aligner, so grade leakage is removed at the EKF's position, not the baseline's (T8.1-CR1 showed a wrong position is what caused the curved_3km offset).

## Prediction (every IMU sample, dt about 0.01 s)
Aligned (valid):
  a = a_long - b
  s <- s + v*dt + 0.5*a*dt^2
  v <- v + a*dt
  b <- b
  F = [[1, dt, -0.5*dt^2], [0, 1, -dt], [0, 0, 1]]
  Q = G G^T sigma_a_long^2 + diag(0, 0, q_b*dt), with G = [0.5*dt^2, dt, 0]^T
  q_b = (bias_rw)^2, bias_rw = 5e-4 m/s^2/sqrt(s): about 0.009 m/s^2 over 300 s, consistent with the flagship drift derived from A14.
Not valid (uncalibrated or in hand): constant-velocity model, acceleration ignored:
  s <- s + v*dt, v <- v, b <- b
  Q = diag(0, q_v*dt, 0) plus the corresponding s-v terms of a velocity random walk, q_v = (v_rw)^2, v_rw = 0.3 m/s/sqrt(s) (the driver's unknown acceleration; A27 gives about 0.14 m/s^2 with 10-50 s periods).
mount_changed: P_bb += (g * sigma_tilt)^2, because the constant offset may have changed with the new mount.

## GNSS update (each fix)
  z = [s_meas, v_meas], s_meas = road_map.project(x, y), v_meas = GNSS speed.
  R = diag((h_acc / 1.5096)^2, sigma_v^2), sigma_v = speed accuracy if present, else 0.2 m/s.
  H = [[1, 0, 0], [0, 1, 0]].
  Reject the fix if its lateral distance from the centerline exceeds lateral_k * h_acc / 1.5096 (single-lane road: a fix far off the road is broken).
  Chi-square gate: d2 = y^T S^-1 y with S = H P H^T + R; reject if d2 > gate_chi2 (13.8, chi-square with 2 dof at 99.9%). Joseph form for the covariance update.

## Weak speed prior
  v is clipped at 0 (vehicles do not reverse in a tunnel).
  If v > speed_limit_factor * speed_limit(s), apply a pseudo-measurement v = speed_limit(s) with sigma v_prior_sigma.

## Initialization and modes
  First GNSS fix: s = s_meas, v = v_meas, b = 0, P = diag(R_ss, R_vv, init_bias_sigma^2).
  Before the first fix: s = 0, sigma_s = 50 m, mode "dead_reckoning".
  mode = "gnss" if a fix was accepted within the last 1.5 s; "recovering" for the first 3 accepted fixes after an outage; otherwise "dead_reckoning". display_s = s (T8.6 adds smoothing). s clamped to [0, road length].

## Parameters (A31 unless noted)
  bias_rw 5e-4 m/s^2/sqrt(s), v_rw 0.3 m/s/sqrt(s), init_bias_sigma 0.1 m/s^2, sigma_v default 0.2 m/s, lateral_k 3, gate_chi2 13.8, speed_limit_factor 1.3, v_prior_sigma 2 m/s.

## Expected behaviour
  Pre-tunnel: b converges in tens of seconds from speed updates.
  Hard brake in the tunnel: v follows the brake, so position stays close (baseline: +663 m).
  Straight constant-speed tunnel: error grows roughly as 0.5 * (residual b) * t^2; sigma_s grows honestly.
  In hand: falls back to constant velocity with growing sigma (comparable to the baseline).

## Addendum: mount yaw error as a state
State x = [s, v, b, d_psi], d_psi = remaining mount yaw error (rad). The aligner's f is off by d_psi, so the measured a_long contains d_psi * a_lat, with a_lat = v * yaw_rate (known from the gyro and v). Corrected acceleration: a = a_long - b - d_psi * v * yaw_rate.
  - d_psi is constant (no process noise). Initial variance: sigma_psi^2 from the aligner when it becomes aligned. On mount_changed, reset d_psi to 0 and its variance to the aligner's new sigma_psi^2 (and keep the P_bb inflation).
  - Jacobian in the aligned prediction: the v row gets dv/d(d_psi) = -v*yaw_rate*dt and the s row -0.5*v*yaw_rate*dt^2; dv/dv also gets -d_psi*yaw_rate*dt.
  - The EKF uses only sigma_base as white acceleration noise; the sigma_psi*|v*yaw_rate| term in sigma_a_long is now carried by the d_psi state, so it is not counted twice.
  - Before the tunnel, GNSS updates through curves can also refine d_psi; nothing else is added for that.
  - Why: the yaw error produces an offset that stays constant through a curve, which white noise cannot represent, so the filter was overconfident in curves.

Implementation notes. The s row also gets ds/dv = dt - 0.5*d_psi*yaw_rate*dt^2 so that the Jacobian is consistent with the prediction. d_psi is also reset (to 0, variance sigma_psi^2 of the new alignment) when a fresh calibration replaces a put-back alignment ("realigned" to "aligned"), because the forward axis changed under it.

Acceptance. The constant-speed-road comparison "EKF exit error no worse than the baseline" is dropped: on a constant-speed road the baseline's last-speed model is nearly exact, while the EKF double-integrates its remaining offset. This is the expected trade-off, which map features and beacons address later.
